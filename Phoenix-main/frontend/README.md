# QuizCrafter Frontend (React + Vite)

This is the standalone React frontend client for **QuizCrafter**, built with **Vite**, **Tailwind CSS**, and **Axios**.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Configure Environment (Optional)
If your FastAPI backend is running on a port other than `8000`, set `VITE_API_URL` in `.env`:
```env
VITE_API_URL=http://localhost:8000
```

### 3. Start Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
The compiled static assets will be output to `dist/`.
